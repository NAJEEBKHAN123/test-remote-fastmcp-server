# FastMCP Remote Server

A minimal FastMCP server exposing `greet` and `add` tools over HTTP.

Run it with:

```bash
python main.py
```

By default, the server listens on `0.0.0.0:8000`. Configure the bind address
and port with `FASTMCP_HOST` and `FASTMCP_PORT`, respectively. The example
server has no authentication; expose it only on a trusted network or behind
